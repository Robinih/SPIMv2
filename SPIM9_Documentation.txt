================================================================================
          SPIM9 - Smart Pest Identification and Monitoring (Android App)
                        FULL PROJECT DOCUMENTATION
================================================================================

Package Name: com.cvsuagritech.spim
Language: Kotlin
Architecture: Single-Activity Navigation (MainNavActivity) with Fragments
Backend API: https://Eyow189.pythonanywhere.com/
ML Models: TensorFlow Lite (PestClassification.tflite, PestDetection.tflite)
Database: SQLite (via PestDatabaseHelper)
Notifications: Firebase Cloud Messaging (FCM) + REST Polling
Auto-Update: GitHub Releases API


================================================================================
                            PAGES / SCREENS OVERVIEW
================================================================================

10. COUNT RESULTS SCREEN
--------------------------------------------------------------------------------
Purpose:
  - Displays the results of insect counting using the TFLite object detection
    model (PestDetection.tflite).
  - Shows the original photo with bounding boxes drawn around detected insects.
  - Red boxes for pests, green boxes for beneficial insects.
  - Shows total count and per-species breakdown with confidence percentages.
  - Automatically saves the count result to the local SQLite database.

Files Involved:
  - CountResultsActivity.kt               (Activity)
  - res/layout/activity_count_results.xml  (Layout)
  - database/PestDatabaseHelper.kt         (Save count record)
  - models/HistoryItem.kt                  (CountItem model)
  - assets/PestDetection.tflite            (Detection model)
  - assets/labels.txt                      (Class labels)

Key Functions:
  - onCreate(): Loads the image path from intent, initializes the model, and
    processes the image.
  - initModel(): Loads PestDetection.tflite into a TensorFlow Lite Interpreter.
  - loadLabels(): Reads class labels from assets/labels.txt. Fallback:
    leafbeetle, leafhopper, pygmygrasshopper, slantfacedgrasshopper.
  - createLetterboxBitmap(): Resizes input to 640x640 with letterbox padding
    (black bars) to preserve aspect ratio.
  - processImage(): Converts image to ByteBuffer, runs inference, parses raw
    output tensor.
  - parseDetections(): Extracts bounding boxes from the model output tensor
    (shape 1x8x8400 or transposed). Applies confidence threshold (0.12).
    Maps coordinates back from letterbox space to original image space.
  - applyNMS(): Non-Maximum Suppression with IoU threshold 0.45 to remove
    duplicate detections.
  - displayResults(): Draws bounding boxes on the bitmap. Red for pests, green
    for pygmy grasshopper (beneficial). Shows total count and per-species
    breakdown.
  - saveCountToHistory(): Saves the annotated image (as JPEG blob), total count,
    and detailed breakdown JSON to the count_records SQLite table.

File: models/PestRecord.kt
  - Represents a single pest identification record.
  - Fields: id, pestName, confidence, imagePath, imageBlob, timestamp, notes,
    isSynced.
  - Helper methods: getFormattedDateTime(), getConfidencePercentage(),
    getConfidenceLevel(), hasImage().

  - Sealed class representing any history record.
  - Two subtypes:
    a) IdentificationItem - Single pest identification with name + confidence.
    b) CountItem - Insect count with total + breakdown JSON.

    - severityLevel (LOW < 5, MEDIUM 5-20, HIGH > 20)
    - getBreakdownMap() - Parses breakdown JSON to Map<String, Int>
      (handles 3 formats: new JSON, intermediate JSON, legacy CSV)
    - getDetailedBreakdown() - Parses breakdown to Map<String, Map<String, Float>>
      (includes confidence per species)

================================================================================
                        ML / MACHINE LEARNING MODELS
================================================================================

1. PestClassification.tflite (in app/src/main/ml/)
   - Image classification model.
   - Input: 224x224x3 image (normalized 0-1).
   - Output: Array of confidence scores per class.
   - Used by: HomeFragment.outputGenerator() for pest identification.
   - Classes (from labels.txt): leafbeetle, leafhopper, pygmygrasshopper,
     slantfacedgrasshopper.

2. PestDetection.tflite (in app/src/main/assets/)
   - Object detection model (YOLO-style).
   - Input: 640x640x3 image (letterbox padded, normalized 0-1).
   - Output: Tensor shape [1, 8, 8400] (bounding boxes + class scores).
   - Used by: CountResultsActivity for insect counting.
   - Post-processing: Confidence threshold 0.12, NMS with IoU 0.45.

Labels File: assets/labels.txt
   - Text file listing class names, one per line.
